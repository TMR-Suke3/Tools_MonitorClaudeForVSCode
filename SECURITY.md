# Security Policy

## Supported Versions

| Version | Supported |
|---|:--:|
| latest `main` | ✅ |
| older releases | ❌ |

## Reporting a Vulnerability

**Please do not open a public issue for security problems.**

Use GitHub's [private vulnerability reporting](../../security/advisories/new).
It is the only channel for this repository — reports stay private until a fix is
published.

Please include:

- what the issue is and how it can be triggered
- affected version / commit
- a minimal reproduction if possible

I aim to acknowledge reports within **7 days** and to publish a fix or a
mitigation plan within **30 days**. Thank you for reporting responsibly.
